Julih & Cia Gestão V16.7 — Status rápido

Na tela Pedidos, cada pedido exibe a próxima ação operacional:
Recebido -> Confirmar pedido
Confirmado -> Iniciar produção
Em produção -> Marcar como pronto
Pronto -> Marcar como entregue
Entregue/Cancelado -> sem botão de avanço

A alteração é enviada ao mesmo Apps Script via updateOrder e depois sincronizada.
O botão Abrir pedido continua disponível para editar todos os dados ou escolher outro status manualmente.
Não é necessário alterar o Apps Script para este recurso.
